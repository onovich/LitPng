# LitPng

[简体中文](README.zh-CN.md)

A browser-local image workbench for batch compression, renaming, resizing, cropping, and conversion.

![LitPng cover](docs/cover.png)

## What it includes

- Runs locally in the browser.
- Batch image transformations.
- No upload required for processing.

## Getting started

Install dependencies and start the local version:

```bash
npm install
npm run dev
```

The repository also provides `npm run build`、`npm run test`.

## Repository map

- `apps/` — Runnable applications.
- `packages/` — Shared packages and domain modules.
- `research/` — Research notes and calibration work.
- `docs/` — Project documentation and design notes.
- `package.json` — Package scripts and dependencies.
