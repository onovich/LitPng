# LitPng

[English](README.md)

浏览器本地批量压缩、改名、缩放、裁切和转换图片的工具。

![LitPng 封面](docs/cover.png)

## 项目包含什么

- 全部处理在浏览器本地完成。
- 批量图像转换。
- 处理过程无需上传图片。

## 快速开始

安装依赖并启动本地版本：

```bash
npm install
npm run dev
```

仓库还提供 `npm run build`、`npm run test`。

## 仓库结构

- `apps/` — 可运行应用。
- `packages/` — 共享包与领域模块。
- `research/` — 研究记录与校准工作。
- `docs/` — 项目文档与设计说明。
- `package.json` — 包脚本与依赖。
